# RAG / Retrieval-Augmented Generation

## 中英文名称

- 中文：检索增强生成
- 英文：Retrieval-Augmented Generation

## 概念

用外部知识库增强大模型回答，减少胡编。

## 作用

让模型回答基于指定资料，适合企业知识库、文档问答。

## 怎么用

1. 文档切块
2. 向量化后存入数据库
3. 用户问题检索相关块
4. 把检索结果加入提示词生成回答

## 总结

RAG = 先检索，再生成。

## 易混淆

- RAG vs Fine-tuning：RAG 改上下文，Fine-tuning 改模型参数。
- RAG vs 长上下文：RAG 是筛选后输入，长上下文是直接输入更多。
