**Agent 的核心是围绕目标自主选择下一步、采取行动，并根据结果调整。**
- **中英文名称**：AI Agent（人工智能体）；AI = Artificial Intelligence（人工智能），Agent 不是缩写。
- **概念与核心能力**：①目标驱动：把目标转成当前要完成的步骤；②动态决策：根据任务状态选择下一步，而非始终照固定顺序执行；③工具行动：在权限内调用检索、代码或文件工具，实际推动任务；④反馈调整：检查结果，必要时修正、重试、求助或停止。复杂规划、长期记忆和多智能体是可选增强，不是所有 Agent 必备。
- **作用**：处理需要多步执行、且中间结果会改变后续做法的任务。步骤固定的工作优先考虑普通流程；Agent 仍需权限边界和结果核验。
- **怎么用**：给出“整理资料并保存到指定笔记”的目标、资料、路径和权限；Agent 找资料，判断是否足够，必要时补查，写入笔记并核验，满足完成标准后停止。
- **总结**：抓住“目标 → 决策 → 行动 → 反馈”；关键不在于会聊天或工具数量多，而在于能依据结果推进任务。
- **易混淆**：Agent vs 固定工作流：Agent 根据结果选择下一步，固定工作流主要沿预设步骤运行。
